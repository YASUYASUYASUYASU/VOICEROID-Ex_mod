	娑婆様が作ってくださったキャラクターの容姿を
	VOICEROID、音街ウナTalk_Ex、CeVIO、ガイノイドTalk、ギャラ子Talkのイメージキャラクターに変更できるmodです

    もしこういうことをやりたい、追加したい、修正したいということで
	困った場合はYasuYasuまでどうぞ

	◆導入方法
	ダウンロードしたzipファイルを解凍して
	modフォルダに配置して頂ければOKです。
